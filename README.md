# m5stack-cardputer-apps
Simple CircuitPython apps for M5Stack Cardputer

Requires the CircuitPython binary that can be obtained from [there](https://circuitpython.org/board/m5stack_cardputer/).

Place the `cardputerMenu2.py` into the startup folder in the cardputer.

The menu code is very unpolished and more improvements coming soon!

Here are the apps, more will be written too:
- CapCodeCalc -> calculate capacitor values.
- ResistorCalc -> calculate resistor values.
